# 这个文件夹是什么

这是 **PulseBar 授权码的密钥**。你以后给订阅者发"免费解锁码"全靠它。

**这是你最重要的东西之一，比软件本身还重要。**

---

## 里面的三个文件

| 文件 | 说明 | 重要性 |
|---|---|---|
| `1_私钥_license-private.key` | **签发授权码用的**，只有你有 | 🔴 极高 |
| `2_公钥_license-public.key` | 验证用的，要内嵌进软件，可以公开 | 🟡 一般 |
| `3_工具_license` | 命令行工具，配合 `.command` 脚本用 | 🟢 备用 |

---

## 为什么要备份

**如果私钥丢了：**
- 你以后**再也发不出新的兑换码**
- 已经发出去的码仍然有效（这个不受影响）
- 想恢复只能重新造一套密钥，但那样老用户就要重新领码

**如果私钥泄露了：**
- 别人可以**伪造你的兑换码**，白嫖你的付费软件

**就这两种结局，都很难受。所以现在去做备份。**

---

## 怎么做备份（选一个或多个）

1. **微信"文件传输助手"** —— 把 `1_私钥_license-private.key` 发给自己（最简单）
2. **密码管理器** —— 1Password / Bitwarden 之类，存成一个"安全笔记"
3. **U 盘 / 移动硬盘** —— 拷一份放进去
4. **邮件草稿** —— 发一封只给自己的邮件，把文件当附件

**至少做两个，其中一个不要只放在这台 Mac 上**（万一硬盘坏了/电脑丢了）。

---

## 换电脑了怎么恢复

1. 把 `1_私钥_license-private.key` 放回 `~/.pulsebar/`，**并且改名回 `license-private.key`**
2. 把 `2_公钥_license-public.key` 同样放回 `~/.pulsebar/`
3. 把 `3_工具_license` 放到 `05_兑换码工具/` 里，改名回 `license`
4. 就能继续发码了

---

## ⚠️ 三条铁律

1. **这个文件夹不要发给任何人**，不要传到网盘/群里/聊天记录里（除非是你自己的备份渠道）
2. **不要把它放进任何要上传到 GitHub 的目录**（我已经帮你排除了）
3. **生成密钥对只能做一次**，重新生成会让所有已发出的兑换码立刻失效
